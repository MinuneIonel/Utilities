# What's new in 0.3.2

**YouTube downloads, for real this time**
- On a Mac with yt-dlp installed through Homebrew, Toolbox used that copy instead of its own, and nothing kept it up to date. An old yt-dlp gets "HTTP Error 403: Forbidden" from YouTube. Toolbox now always uses its own yt-dlp, which it keeps current, and only falls back to another copy when it can't download its own.
- Your own yt-dlp settings file, if you have one, no longer changes where Toolbox's downloads go.
