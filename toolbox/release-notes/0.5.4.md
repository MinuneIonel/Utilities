# What's new in 0.5.4

**Batch encode videos**
- New **Several videos** input: choose or drop a pile of videos at once. Render encodes each one, and Save writes one file per video, named after the original.
- Two new workflows: **Encode a batch of videos** and **Encode a folder of videos**. Pick the format, codec (including ProRes and HEVC) and quality.
- The cards show which file they're on, like "File 3 of 12 · Encoding 40%".
- **Cancel keeps the finished files.** Stop a long batch halfway and the videos already done are saved. With **Only new files**, the rest are picked up next time.
