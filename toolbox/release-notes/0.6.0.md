# What's new in 0.6.0

**A clearer settings panel**
- Each setting now has its name above it and the whole width for its control, so long names and choices no longer get cut off.
- Sliders fit what you're working on: once a node has run, "Show video" lists the playlist's videos by name, positions show a time, sizes stop at the picture's size, and counts follow the input. You can still type any number.
- Hints in brackets turn into grey help text, on/off settings are switches, and each setting has a ↺ button to put back its default.

**YouTube downloads that ask "confirm you're not a bot"**
- **Download from link** has a new **Use sign-in from** option (Chrome, Safari, Firefox, Edge or Brave). Toolbox borrows that browser's YouTube sign-in, which usually gets past the check.
- Playlists now pause a few seconds between videos, so YouTube is less likely to ask at all.
- If YouTube still stops a playlist halfway, the videos already downloaded are kept: Render again picks up where it stopped. Error messages now say in plain words what to do.

**Video encoding that doesn't get stuck**
- When the normal encoder can't handle a file, the desktop app now re-encodes it with its built-in ffmpeg, which is fast and handles big files. Before, it could sit on "Retrying with ffmpeg.wasm…" for a very long time.
- Cards always show the current step instead of an old one.
