# What's new in 0.5.3

**Download whole playlists**
- Paste a playlist link into **Download from link** and it gets every video. Works with YouTube playlists, SoundCloud sets, Bandcamp albums and Vimeo showcases.
- A YouTube video link that's part of a playlist asks whether you want the whole playlist or just that video.
- **Which videos** picks only some, like `1-10, 15, 20-`.
- Save puts them in a folder named after the playlist, numbered in playlist order. Private or broken videos are skipped and the rest keep going.
- New quality, **Sound only, as MP3**. The **Download the sound as MP3** workflow uses it, so it now works for whole playlists too.

**Folder of files: videos, sounds and PDFs**
- **Folder of files** now takes videos, sounds or PDFs as well as photos. Pick which with the new **Files** setting.
- Render runs the rest of the graph once for each file, and Save writes one result per file, keeping the sub-folders.
- If one file fails, the others still get done, and **Only new files** tries the failed one again next time.
- Two new workflows: **Shrink a folder of videos** and **Convert a folder of sounds**.
