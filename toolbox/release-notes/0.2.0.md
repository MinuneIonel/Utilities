# What's new in 0.2.0

**Editing**
- Undo and redo (⌘Z / ⇧⌘Z, Ctrl on Windows and Linux), plus cut, copy, paste and duplicate (⌘D) for nodes, from a real Edit menu.
- A short first-run tutorial, which you can reopen from the **?** button or Help → Tutorial.
- **Workflows** replace Templates: ready-made chains for downloading a video or its sound as MP3, extracting audio, shrinking a video, video to GIF, compressing or watermarking photos, and more. Search finds them in the Tab menu too.
- Clearer node names, a resizable inspector you can hide, and no more red errors on empty inputs.

**Photos**
- Batch processing: drop several images and every node after them runs on each one. Save writes one file per image, named after the originals, into a folder you pick once.
- New **Text / logo overlay** node: text, a logo, or both, placed on a 3×3 grid with size, colour, opacity and margin. It works on photos, videos and batches.
- iPhone HEIC photos open in the Mac app.

**Video and sound**
- Video file has Start, End and Speed, and a playhead scrubber in the big view.
- Webcam records sound too (on by default), and two Encode video nodes can share one recording.
- Download from link has a File output with the download as it came.

**Rendering and saving**
- Render only rewrites Save nodes whose result changed. Each Save node also has its own Save button.
- Saving into a folder never overwrites: you get `name (2).ext` and so on.
- With no Save node, Render adds one after the selected node. One Save node takes images, text, sound, PDFs and videos.
- Dropped files are remembered and read again after a restart or when you open a graph.
- Large videos use less memory: ffmpeg reads files straight from disk.

**Updates**
- Toolbox tells you when a newer version is on GitHub.
