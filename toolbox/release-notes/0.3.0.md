# What's new in 0.3.0

**Updates itself**
- When a newer Toolbox is out, press **Update** in the top bar. It downloads in the background, then **Restart to update** closes Toolbox, puts the new version in place and opens it again with your graph as it was.
- Help → **Check for Updates…** checks right away.
- Every download is checked against the checksum GitHub publishes for it before it's installed.
- On a Mac this works when Toolbox is in Applications. If it can't update itself, you get a link to this page instead.

Coming from 0.2.0 or older? Download this version by hand once. From here on Toolbox updates itself.
